# Case Study: Hotel Reservation System Modernization

## Situation
A growing hotel relied on manual and Excel-based processes to manage reservations, room availability, customer records, and guest check-in/check-out activities.

## Problem
The existing workflow was inefficient, error-prone, and difficult to scale as reservation volume increased. Staff needed a faster and more reliable way to access reservation and room information.

## Task
Design and plan a centralized Microsoft Access system to improve operational accuracy, service speed, room tracking, and staff usability.

## Action
Using a traditional SDLC / Waterfall approach, the project team:

- Created a business case and project charter
- Defined project purpose, scope, assumptions, risks, and success criteria
- Developed a stakeholder register and communication expectations
- Completed feasibility and cost-benefit analysis
- Built a Work Breakdown Structure for project phases and deliverables
- Planned database development, data migration, testing, training, deployment, and monitoring
- Designed Access-based workflows involving tables, forms, validation rules, and reservation operations

## Result / Value
The project demonstrated how a low-cost Microsoft Access database could support operational modernization by reducing booking errors, improving room tracking, streamlining daily reservation processes, and improving guest service.

## Methodology Used
This project used a **traditional SDLC / Waterfall project management methodology**.

The Agile/Scrum materials belong to a separate dashboard-planning project and are intentionally not included as the primary methodology for this repository.
