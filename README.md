# Hotel Reservation System Modernization

## Overview
This project modernized a manual and Excel-based hotel reservation workflow by planning and developing a centralized Microsoft Access database system.

This project was completed using a **traditional SDLC / Waterfall project management approach**, including initiation, planning, execution, testing, deployment planning, and closing evaluation.

## Business Problem
The hotel's existing manual and spreadsheet-based process created several operational issues:

- Slow reservation tracking
- Increased risk of booking and data-entry errors
- Limited room availability visibility
- Delayed check-in and check-out processes
- Administrative burden on staff
- Difficulty scaling as customer volume increased

## Proposed Solution
A Microsoft Access database designed to centralize:

- Reservations
- Room availability
- Customer records
- Check-in/check-out status
- Basic reporting and operational tracking

## Project Management Methodology
This project used a **SDLC / Waterfall methodology** with the following phases:

1. Initiation
2. Planning
3. Execution
4. Testing
5. Deployment Planning
6. Closing / Post-Project Evaluation
